# 呦呦剧场

给马呦呦定制的 Android TV 本地小猪佩奇播放器，不依赖腾讯视频会员和投屏。

## 已有功能

- 启动欢迎语：欢迎马呦呦小朋友。
- 集数约定：默认 4 集，最多 12 集；焦点在集数卡片或加减按钮上时，遥控器上/下键可调整。
- 内容类型：正常版、迷你版、随便看。
- 视频来源：首次用系统目录选择器选择 U 盘或电视存储里的视频目录，授权会自动记住。
- 播放控制：播放时遥控器右/左键快进/后退 10 秒，确认键暂停/继续；每集正常播放结束后显示“看看窗外”20 秒休息倒计时，随后自动连播；最后一集倒计时结束后出现结束画面，家长长按确认键 3 秒才能退出。
- 语音提示：进入时播报约定集数，每集开始播报当前集数和剩余集数，结束后播报休息提醒。
- 文件排序：按自然数字排序，`第2集` 会排在 `第10集` 前面。
- 每日额度：默认每天最多 4 集，跨天自动重置；家长也可以手动重置当天额度。
- 观看记录：看完一集才计入“已看完”；“随便看”会优先抽没看过的集数，全部看完前不重复。
- 断点续播：没看完的集会记住进度，下次从原位置继续；快到结尾的进度不会保存。
- 家长中心：首次打开时设置 4-6 位数字密码，之后可以修改密码、调整每日额度、重置当天额度、清空观看记录和断点。

## U 盘文件建议

在 U 盘建一个目录，例如 `PeppaPig`，把视频放进去并按集数命名：

```text
PeppaPig/
  第01集.mp4
  第02集.mp4
  第03集.mp4
  迷里第01集.mp4
  迷你第02集.mp4
```

- 文件名包含 `迷你`、`mini`、`短片` 或 `小小的` 会归入“迷你版”。
- 其他视频归入“正常版”。
- 支持递归读取 6 层子目录，扩展名包括 `mp4`、`mkv`、`avi`、`mov`、`webm`、`m4v`、`3gp`、`ts`。

## 安装

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Android TV 首页会显示“呦呦剧场”的电视横幅图标。

模拟器没有 U 盘时，先执行：

```bash
adb shell mkdir -p /sdcard/Movies/PeppaPig
adb push /path/to/video.mp4 /sdcard/Movies/PeppaPig/
```

然后点击 App 的“选择视频位置”：如果模拟器有系统目录选择器，选择 `Internal storage / Movies / PeppaPig` 并点击 `SELECT`；部分 Android TV 模拟器只有 `com.android.tv.frameworkpackagestubs/.Stubs$DocumentsStub`，不提供真正的目录选择器，App 会改为读取本机/模拟器媒体库（首次使用需允许视频读取权限）。这种方式可以测试视频播放，但无法测试 U 盘目录选择与授权；后者需使用带目录选择器的系统镜像或真机。

如果 `adb push` 后仍提示没有视频，先查询媒体库中的文件状态：

```bash
adb shell content query --uri content://media/external_primary/video/media --projection _id:_display_name:is_pending
```

部分模拟器会把推入的文件标为 `is_pending=1`，普通 App 无法看到。确认文件已完整传输后，按查询结果中的实际 `_id`（不要照抄示例 ID）将其发布：

```bash
adb shell content update --uri content://media/external_primary/video/media/实际ID --bind is_pending:i:0
```

重新打开 App 后再选择视频位置。

## 语音说明

应用使用系统 TTS。如果电视没有安装中文 TTS 引擎，语音不会报错，但所有“这是第几集、还剩几集”的文字提示仍会显示。可在电视设置的无障碍/文字转语音里安装或启用中文语音包。

## 家长中心说明

1. 首次点击“家长中心”会要求设置 4-6 位数字密码；建议家长安装后先设置，再交给小朋友。
2. “每日最多集数”可设置为 1-12 集，默认 4 集。
3. “重置今日观看额度”只重置当天已看数量，不会删除看完记录。
4. “清空观看记录和断点”会删除全部已看完标记和播放进度，用于重新开始片单。
5. “重置家长密码”需要先通过当前密码进入家长中心。
6. 如果密码遗忘，只能清除应用数据或卸载重装；这也会清除视频位置、观看记录和额度设置。
